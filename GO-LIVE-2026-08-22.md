## Safer staged option

Drop `--announce-live` to preview the launch email (dry-run) instead of sending,
and drop `--promo` to skip the YouTube Short. Example minimal (registry + site only):

```bash
npm run go-live -- --slug=<slug> --udemy=<url>
```

Add `--dry-run` to print the steps without executing.

## After each run
- Commit + push the regenerated `site/` to the GitHub Pages repo (technuggets.academy).
- Verify the YouTube Short is public and its description link resolves.
- (Optional) add the course to the monthly free-coupon batch when the next
  `FREETEST33`-style coupons are generated.

## Notes / gotchas
- Only run once the course is LIVE — site + promo links 404 while it's in review.
- If you launch several at once, pass `--no-site` on all but the last, then run
  `node scripts/build-practice-site.js` once at the end to rebuild the site a single time.
- Course URLs are permanent; the trailing `-w` / `-g` suffixes are Udemy's
  uniqueness chars and are part of the real URL.
