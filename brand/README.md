# TechNuggets Academy — brand assets

Official logo: the **gold nugget** — a faceted amber hexagon (nugget + cert-badge shape) with a knowledge spark.

## Files
| File | Use |
|---|---|
| `technuggets-icon.svg` | master icon (square, transparent) — scale to anything |
| `technuggets-logo-horizontal.svg` | icon + wordmark, for **light** backgrounds |
| `technuggets-logo-horizontal-dark.svg` | icon + wordmark, for **dark** backgrounds (white "Tech") |
| `favicon.ico` | site favicon (16/32/48 multi-res) |
| `png/technuggets-icon-{16..1024}.png` | app icons, card badge, social avatar (512/1024) |
| `png/apple-touch-icon-180.png` | iOS home-screen icon |
| `png/technuggets-logo-horizontal-{600,1200,2400}.png` | site header, email, docs (light bg) |
| `png/technuggets-logo-horizontal-dark-{600,1200,2400}.png` | dark hero / dark email |

Which size to use: **favicon** → `favicon.ico`; **site header** → horizontal-600 or the SVG; **email footer** → horizontal-600 (PNG, for client support); **social/avatar** → icon-512; **course-card badge** → icon-128/256; **print/hi-res** → 2400 PNG or the SVG.

## Brand colors
| Name | Hex | Use |
|---|---|---|
| Nugget amber | `#F59E0B` | primary mark, "Nuggets" wordmark |
| Amber dark | `#B45309` | mark outline |
| Amber light | `#FBBF24` | highlights |
| Ink navy | `#0F172A` | "Tech" wordmark, body text |
| Slate | `#475569` | "ACADEMY" sub-label |
| White | `#FFFFFF` | spark, on-dark wordmark |

Pairs with the site/CTA palette: sky `#0EA5E9` (links/trust), orange `#F97316` or green `#22C55E` (CTAs).

## Clear space & don'ts
- Keep clear space around the mark ≥ the height of the hexagon's top edge.
- Don't recolor the hexagon, stretch the lockup, or add effects/shadows.
- Min sizes: icon 16px; horizontal lockup ~120px wide.
- The wordmark PNGs bake the font in, so they render identically everywhere; the SVGs use DejaVu Sans / Arial fallback (swap to your brand font later if you license one).
